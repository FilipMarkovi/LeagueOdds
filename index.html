LoL Winning Odds Predictor

Predicts Blue vs Red win probability from live match state using simple team-difference features: game time, gold diff, level diff, towers, dragons, barons, and void grubs.

How it works

  • Preprocess: raw interval snapshots are converted into team-diff features per match-minute.
  • Train: XGBoost learns whether Blue team wins from those features.
  • Evaluate: outputs overall accuracy + accuracy by 5-minute checkpoints.
  • Live mode: reads LoL Live Client API and prints win chance every 5 in-game minutes.

Feature schema used

  • game_time (minutes)
  • gold_diff (blue total gold - red total gold)
  • level_diff (sum of champion levels, blue - red)
  • towers_diff, dragons_diff, barons_diff, void_grubs_diff
  • target: blue_win (1 if Blue wins)

Built for fast iteration: add richer features later without changing the main workflow.
